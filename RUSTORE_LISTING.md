## Короткое описание (до 80 символов)
Разбор техники теннисной подачи по видео — прямо на телефоне, без интернета

_(вариант короче, если лимит меньше)_:
Разбор теннисной подачи по видео — офлайн, на устройстве

## Полное описание

**Анализатор подачи** — приложение для теннисистов, которое разбирает технику
подачи по видео прямо на телефоне. Никаких загрузок в облако: вся обработка
(поза, детекция мяча и ракетки, оценка) идёт локально, на нейропроцессоре
устройства.

**Как это работает**
Запиши подачу на камеру телефона (или выбери готовое видео из галереи) — и
получи разбор по фазам: стойка → подброс → трофей → замах → удар → завершение.
Приложение показывает скелет движения, момент контакта с мячом и отмечает,
что стоит улучшить в технике.

**Возможности**
• Разбор подачи по фазам с оценкой каждого этапа
• Несколько подач в одной записи — каждая разбирается отдельно
• Детекция мяча и ракетки с учётом смазанности кадра при быстром движении
• Экспорт видео с наложенным скелетом и рамками объектов — можно пересмотреть
  или отправить тренеру
• Голосовые подсказки на русском языке после каждой подачи
• Режим реального времени — живой трекинг фаз с подсказками во время тренировки
• История подач и сравнение двух записей side-by-side
• Работа без интернета — всё считается на устройстве

**Для кого**
Игрокам, которые хотят разобрать свою технику подачи самостоятельно между
тренировками, и тренерам — для наглядного разбора с учеником.

Приложение бесплатное, содержит рекламу.
